# Festival image attribution

Every photograph in this folder is a real image **of the specific festival it is
attached to**, downloaded from Wikimedia Commons under a free licence. Festivals
without a suitable photograph are deliberately left without one so the app shows
the entry's own icon instead of an unrelated picture.

`lib/data/festival_image_credits.g.dart` is generated from this list by
`tool/fetch_festival_images.ps1`; edit that script rather than the generated
file.
